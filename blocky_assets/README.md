# Blocky 3D asset library ("In this town…" story Shorts)

Original low-poly blocky characters, props, sets and textures, modelled after what appears in the
reference reels (see `SOURCES.md`). Everything is generated by code in `tools/` and can be rebuilt or extended.

## Folder layout

```
models/characters/*.glb        poseable blocky avatars + chicken
models/props/<category>/*.glb  sewing_room, school, home, town, nature, event, fx
textures/faces/                20 expressions (plus _lashes variants), 512px transparent PNG
textures/outfits/              shirt / jacket / dress patterns
textures/signs/                shop signs, calendar pages DAY 1-30 + weekdays, newspaper, speech bubbles
textures/surfaces/             wood, brick, siding, windows, road, tiles, cobble, grass
textures/sky_fx/               sky gradients, night stars, rain streaks, glow sprites
reference_frames/<video_id>/   scene-change stills from each reference video
previews/                      a PNG render of every model
catalog.json                   machine-readable index (ids, files, notes, bounds)
tools/                         generators (python3 tools/build_all.py) + preview renderer
```

## Conventions

- glTF 2.0 binary (`.glb`), textures embedded. Opens in Blender, three.js, Unity (glTFast), Godot and Unreal.
- Metres, +Y up, front faces +Z, base/feet at y = 0. A character is about 1.6 m tall.
- **Character rig**: the root has `hips`, which holds `torso`, `leg_L/R` (pivot at the hip), `arm_L/R` (pivot at
  the shoulder) and `neck` → `head` → `face`. Rotate those nodes to pose: walk, wave, point, sit and so on.
- **Expressions**: the `face` node is a quad with its own material (`face_<id>`). Swap its base-color
  texture for any `textures/faces/face_<expression>.png` (use the `_lashes` files for characters with eyelashes).
- Swappable parts: `calendar` → `page` node (use `textures/signs/calendar_day_XX.png`), `mood_dial` → `needle`
  node (rotate Z), `flashlight` → `beam` node (hide or show), `car` material `car_paint` (recolour).
- Glowing items (lamps, mushrooms, windows at night, lightning, sun) use emissive materials. Add bloom for the glow.
- Rain: put `rain_sheet` in front of the camera and scroll its UV offset downward.

## Rebuild / extend

```
cd blocky_assets
python3 tools/build_all.py                 # everything
python3 tools/build_all.py stripe_kid car  # only these ids
```
New characters go in `characters.cast()` and new props are `@prop(...)` functions in `props.py`.
